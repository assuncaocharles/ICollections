TypeScript · zero dependencies · ESM

Data structures you can see working.

Eight strictly typed collections for TypeScript and JavaScript, from a binary search tree to a hash table. Each one is iterable, fully tested, and has an interactive visualization.

TypeScript
{{ts:import { BST, PriorityQueue } from 'icollections';

const bst = new BST([50, 30, 70, 20, 40, 60, 80]);
bst.has(60);      // true, after 3 comparisons
bst.inOrder();    // [20, 30, 40, 50, 60, 70, 80]
bst.findMin();    // 20

// Any type, with a comparator
const byAge = new BST([], (a, b) => a.age - b.age);

// Lowest priority number first; ties keep their order
const jobs = new PriorityQueue();
jobs.enqueue('deploy', 2);
jobs.enqueue('hotfix', 1);
jobs.dequeue();   // 'hotfix'

for (const value of bst) console.log(value); // in order}}
The collections

Eight structures, one consistent API

Every collection takes initial values in its constructor, works with for...of and spread, and returns undefined instead of throwing when it is empty.

BST Sorted values with O(log n) search. Any type, with a comparator. add has remove inOrder LinkedList Nodes linked head to tail. O(1) append with a tail pointer. add addAt removeAt indexOf Stack Last in, first out. O(1) push and pop. push pop peek Queue First in, first out. Amortised O(1) at both ends. enqueue dequeue front PriorityQueue A stable binary heap. O(log n) enqueue and dequeue. enqueue dequeue front HashTable String keys hashed into buckets, with separate chaining. add lookup remove Set Unique values with union, intersection and difference. union intersection subset Map Keys of any type, compared by value or by reference. set get delete
Why ICollections

Small, strict and predictable

{{icon:shield}}

Strict types

Generic everywhere, no any. Reads from an empty collection are typed T | undefined, so the compiler reminds you to check.

{{icon:loop}}

Iterable

Use any collection with for...of, spread or Array.from. A tree iterates in order, a stack from the top.

{{icon:feather}}

Zero dependencies

Tree-shakeable ES modules with no runtime dependencies. Import only what you use.

{{icon:layers}}

No stack overflows

Every tree operation is iterative, so even a tree built from sorted input cannot overflow the call stack.

{{icon:check}}

Thoroughly tested

Full line coverage, plus randomized tests that check each structure against a reference implementation.

{{icon:play}}

Learn by watching

The playground animates every operation step by step and writes the matching code as you go.
